# CareSprint

## On-Demand At-Home Healthcare Platform

CareSprint is a location-aware healthcare platform designed to connect
patients with nearby verified doctors for at-home consultations across
Bhilai, Durg, and Raipur.

## Core Features

- Patient authentication
- Doctor registration and verification
- Location-based doctor discovery
- Intelligent doctor matching
- At-home booking
- Real-time booking updates
- Live doctor tracking
- Digital prescriptions
- Online payments
- Reviews and ratings
- Admin dashboard
